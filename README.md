# 五台山顺朝大朝台 · 3天2夜重装徒步攻略

一个单文件的可交互徒步攻略页面。电脑和手机端都能用，地图、海拔剖面、物资清单都支持交互。

## 打开方式

- **在线看**：https://<你的用户名>.github.io/<仓库名>/
- **本地看**：直接双击 `index.html`（无需服务器、无需联网即可查看地图与行程；仅实时天气和在线底图需要网络）

## 页面内容

| 模块 | 说明 |
|---|---|
| 出发日期 | 可自定义出发日，全站日期、天气、行程自动联动（存在浏览器本地） |
| 天气气温 | 所选日期的实时预报；超出 16 天预报窗口时自动切换为十年同期均值 |
| 交互地图 | 2D 地形图 + 3D 山体，18 个关键点位分 7 类（五台顶 / 云海观景 / 补给点 / 露营住宿 / 上科技 / 下撤点 / 垭口节点） |
| 三日行程 | 每日里程、爬升、下降、逐时段时间轴；附 5 套分日方案对比 |
| 物资清单 | 62 项逐项克重，可勾选并实时累计重量 |
| 交通费用 | 到达/返程方式、门票与挂单费用、行前节奏 |
| 参考来源 | 全部外部资料的原始链接 |

## 数据来源

- **轨迹与高程**：两步路导出的《五台山顺朝》KML（23,733 个轨迹点，顺时针顺朝），里程与爬升按全分辨率计算
- **地形底图**：AWS Terrain Tiles（terrarium 编码，z13 约 15 m/px），重采样为 641×641 网格（约 33 m 间距）驱动 2D 山体阴影与 3D 网格
- **气象**：Open-Meteo 预报 API 与 ERA5 历史再分析（2016–2025）
- **走线核对**：OpenStreetMap「五台山环线」徒步关系

## 说明

- 页面依赖的外部服务（Open-Meteo 天气接口、高德/必应地图瓦片、Leaflet CDN）均需联网；离线时页面其余部分仍可正常使用。
- 本页为信息整合与行程参考答案，不构成安全担保。山区天气、路况、寺院开放与收费标准请以现场为准。
